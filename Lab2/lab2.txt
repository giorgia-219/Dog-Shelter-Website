Aufgabe 1 – CSS

- Was ist ein CSS Selector und welche Selektoren stellt CSS zur Verfügung.
Ein CSS Selector ist ein Name, mit dem man HTML Elemente auswählt, um sie zu stylen. CSS stellt verschiedene Selektoren bereit: Element, Klasse, ID und Universal (*). Selektoren können auch verkettet werden.

- Was versteht man unter dem Boxmodell und wann ist es relevant.
Das Boxmodell ist die Art, wie CSS den Platz für ein Element rechnet. Es besteht aus Margin, Padding, Border und Content. Es ist immer dann relevant, wenn man Abstände und Größen auf der Seite plant. 

- Wie können verschiedene Schriftarten in CSS definiert werden?
Schriftarten können in CSS auf zwei Arten definiert werden: mit der Eigenschaft font-family (direkter Befehl) oder kann man sie in einer Variable wie $font in SASS speichern.
